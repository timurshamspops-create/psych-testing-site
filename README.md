# Психологическое тестирование — сайт для соцпроекта (тема 19)

Статический сайт для GitHub Pages: список опросов (Google Forms), встроенное
прохождение опроса, страница статистики и страница контактов.

## Структура

```
index.html          — список опросов (карточки)
survey.html          — встроенная Google Form по ?id=...
results.html         — статистика прохождений
contacts.html        — контакты разработчика
data/surveys.json    — список опросов: id, название, описание, ссылка на форму
css/style.css        — вся стилизация
js/main.js           — загрузка surveys.json + рендер карточек
js/survey.js         — логика страницы конкретного опроса
js/results.js        — логика страницы статистики (график Chart.js)
apps-script/Code.gs  — пример скрипта для получения реальной статистики
```

## Шаг 1. Подключить свои опросы

Откройте `data/surveys.json` и замените `formUrl` у каждого опроса на ссылку
на вашу Google Form (обычная ссылка вида
`https://docs.google.com/forms/d/e/.../viewform` подойдёт — `survey.js`
сам добавит параметр встраивания).

Можно добавлять и убирать опросы — просто редактируйте этот JSON-файл,
поля `id`, `title`, `category`, `description`, `duration`, `formUrl`.

## Шаг 2. Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите туда все файлы этого проекта.
2. В репозитории: **Settings → Pages**.
3. В разделе **Source** выберите ветку `main` и папку `/root`.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<название-репозитория>/`.

На этом этапе сайт уже полностью рабочий: опросы открываются, встраиваются
и проходятся. Страница статистики будет показывать демонстрационные данные,
пока не выполнен шаг 3.

## Шаг 3 (опционально). Реальная статистика вместо демо-данных

По умолчанию все ответы каждой Google Form попадают в её собственную
таблицу, и достать их на статический сайт напрямую нельзя — нужен
небольшой "мост" в виде Google Apps Script.

1. Создайте одну общую Google Таблицу для статистики.
2. В каждой Google Form: **Ответы → значок таблицы → выбрать существующую
   таблицу** → укажите эту общую таблицу. Google создаст в ней отдельный
   лист для каждой формы — переименуйте эти листы так, чтобы их названия
   совпадали с `id` опросов в `surveys.json` (`big5`, `gad7`, `eq`).
3. В общей таблице откройте **Расширения → Apps Script** и вставьте туда
   код из `apps-script/Code.gs`.
4. **Deploy → New deployment → Web app**, Execute as: *Me*,
   Who has access: *Anyone*. Скопируйте полученный URL.
5. В `js/results.js` вставьте этот URL в переменную `APPS_SCRIPT_URL`.

После этого страница результатов будет показывать реальное количество
пройденных опросов вместо демо-данных.

## Шаг 4. Контакты

Откройте `contacts.html` и замените имя, email, Telegram и GitHub на свои.

## Локальный просмотр

Так как страницы подгружают `data/surveys.json` через `fetch`, при простом
открытии файла `index.html` двойным кликом браузер может заблокировать
загрузку (ограничение `file://`). Проще всего проверить сайт локально
через простой сервер, например:

```
npx serve .
```

или через встроенный сервер Python:

```
python3 -m http.server
```

и открыть `http://localhost:8000`.
